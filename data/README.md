# Kadiwéu data

This directory contains source data and generated resources used in the
conversion of the Kadiwéu constituency treebank to Universal Dependencies.

## Tycho Brahe source corpus

The source annotations come from the *Corpus Kadiwéu – gramática pedagógica*
on the Tycho Brahe Platform.

On the platform, a **corpus** consists of one or more **documents**. The
Kadiwéu corpus currently contains three documents. Each document contains
Kadiwéu sentences, metadata, and linguistic annotations.

The JSON and PSD files downloaded from the platform have opaque, unstable
filenames. This repository therefore assigns each document a stable short
identifier and creates canonical filenames based on that identifier.

| Repository document identifier | Tycho Brahe document title | Document UID | Canonical JSON file | Canonical PSD file |
|---|---|---|---|---|
| `ped-gramm` | Dados para a gramática do sintagma nominal | `28eeb8a0-d923-4d75-aebe-599aadddfbbb` | `ped-gramm.json` | `ped-gramm.psd` |
| `hil-data` | dados do Hilário abril de 2026 | `ffef8450-e302-4882-8306-e5998d31f584` | `hil-data.json` | `hil-data.psd` |
| `van-data` | Vanda dados | `9d0f60a9-8c32-44c0-ac68-0b5d5b993db8` | `van-data.json` | `van-data.psd` |

## History of the `ped-gramm` identifier

The identifier `ped-gramm` was introduced when the *Corpus Kadiwéu – gramática
pedagógica* contained only one document. At that time, the distinction between
the corpus and its single document was not operationally important.

After the Hilário and Vanda documents were added, the original document was
renamed *Dados para a gramática do sintagma nominal* on the Tycho Brahe
Platform. The repository retained `ped-gramm` as its stable document identifier
in order to preserve existing filenames, sentence identifiers, scripts,
reports, and provenance records.

The following names therefore have distinct referents:

| Name | Referent |
|---|---|
| *Corpus Kadiwéu – gramática pedagógica* | The entire corpus on the Tycho Brahe Platform |
| *Dados para a gramática do sintagma nominal* | One document within that corpus |
| `ped-gramm` | The stable repository identifier for that document |

The identifier `ped-gramm` should not be interpreted as the current title of
the source document or as the identifier of the entire corpus.

## Naming policy

Repository document identifiers remain stable even if document titles on the
source platform change. Current titles and stable Tycho Brahe document UIDs
are recorded in this README.

Use:

- `ped-gramm`, `hil-data`, and `van-data` in filenames, sentence identifiers,
  scripts, command-line options, and generated resources;
- the full Tycho Brahe document titles when identifying the source documents
  in scholarly prose;
- *Corpus Kadiwéu – gramática pedagógica* only when referring to the entire
  Tycho Brahe corpus.

## Tycho Brahe export archive

The unmodified downloaded JSON and PSD exports are archived under `tycho/`.
Their opaque filenames and their correspondence to the canonical working files
are recorded in `tycho/README.md`.

That README is generated by `src/refresh_kadiweu_jsons.sh` and should not be
edited manually.
